## 開始前準備

1. 到 GitHub 的 [`彙整版/`](../彙整版/) 下載 `底稿.pbix`，雙擊用 Power BI Desktop 開啟。
2. **檔案 → 另存新檔**，存成 `自己名字_圖表_1124_V1.pbix`（例如 `Tim_圖表_1124_V1.pbix`）。之後都在這個檔案上做。
3. 左側切到 **報表檢視**（長條圖圖示），下方頁籤應有 `Page1_總覽`、`Page2_診斷` 兩頁。
4. 畫面右側有兩個窗格：
   - **視覺效果**：選圖表類型、放欄位、調格式（筆刷圖示＝格式、放大鏡圖示＝分析）
   - **資料**：所有欄位和量值都在 `解散清冊` 底下（量值前面有計算機圖示）

**通用做法**：先點一下畫布空白處 → 在「視覺效果」窗格點圖表圖示 → 畫布出現空白圖表 → 從「資料」窗格把欄位**拖曳**到「視覺效果」窗格的對應格子（例如「X 軸」）→ 拖圖表邊角調大小、拖中間移位置。

> 一定要先點空白處再選圖表類型，不然會把已經選取的圖表換掉。

**做完後**：對照每張圖的 ✅ 數字 → **檔案 → 儲存** → GitHub 進入自己名字的資料夾 → **Add file → Upload files** → 拖入 `.pbix` → 寫「名字 圖表 V1」→ **Commit changes** → 在群組說一聲。

## 1. 群組橫條圖（縣市排名）— Page 1

1. 點 `Page1_總覽` 頁籤 → 點空白處 → 視覺效果窗格點 **群組橫條圖**（橫向長條的圖示）。
2. 拖曳欄位：
   - `縣市` → **Y 軸**
   - `總解散家數` → **X 軸**
   - `公司型態` → **圖例**
   - `短命公司率` → **工具提示**
3. 排序：點圖表右上角 **⋯（更多選項）** → **排序軸** → 選 `總解散家數`，再選 **遞減排序**。
4. 排除「地址缺漏」：右側 **篩選** 窗格 → 「此視覺效果上的篩選」找到 `縣市` → 展開後取消勾選「地址缺漏」（或勾「全選」後再取消它）。
5. 格式 → **標題** 改成「各縣市解散家數」。
6. 放在 Page 1 下方左邊，拉高一點，讓 22 個縣市都看得到。

✅ 檢查：第一名臺北市 27,616、第二名新北市 21,683、第三名臺中市 16,465；滑鼠移到臺北市顯示短命率 8.2%。

## 2. 堆疊直條圖（資本額級距 × 存活區間）— Page 1

1. 點空白處 → 視覺效果窗格點 **堆疊直條圖**（直條一節一節疊起來的圖示）。
2. 拖曳欄位：
   - `資本額級距` → **X 軸**
   - `總解散家數` → **Y 軸**
   - `存活區間` → **圖例**
3. 確認 X 軸順序是「0或缺漏、10萬以下、10-50萬…1億以上」：點 ⋯ → **排序軸** → 選 `資本額級距`、**遞增排序**。如果順序亂掉，代表底稿的「依資料行排序」沒設好，在群組講。
4. 改顏色：格式 → **資料行**（或 **直條**）→ 上方「套用設定至」**數列** 選「1年以下」→ 色彩選**紅色**。其他區間可用淺色，讓紅色更明顯。
5. 格式 → **標題** 改成「資本額級距 × 存活年數」。
6. 放在 Page 1 下方右邊。

✅ 檢查：「10萬以下」整根約 11,456 家，其中紅色（1年以下）佔比最高（23.6%）。

## 3. 散佈圖（資本額 vs 存活年數）— Page 2

1. 點 `Page2_診斷` 頁籤 → 點空白處 → 視覺效果窗格點 **散佈圖**（散落圓點的圖示）。
2. 拖曳欄位（順序很重要，先放「值」）：
   - `統一編號` → **值**（每家公司一個點）
   - `存活年數` → **X 軸**
   - `資本額` → **Y 軸**
   - `地址群聚` → **圖例**
   - `公司名稱` → **工具提示**
3. 確認 X、Y 軸沒有被加總：點 X 軸格子裡 `存活年數` 旁的小箭頭 → 選 **不要摘要**；Y 軸 `資本額` 同樣設定。（底稿已設好的話會自動是「不要摘要」）
4. Y 軸改對數：格式 → **Y 軸** → **尺規類型** 選 **對數**（資本額差距太大，不改的話點會全擠在底部）。
5. 改顏色：格式 → **標記** → 「群聚地址(≥3家)」選**橘色**、「一般地址」選**灰色**。
6. 加短命線：點視覺效果窗格的 **放大鏡圖示（分析）** → **X 軸常數線** → **新增** → **值** 輸入 `1` → 開啟 **資料標籤**，標題輸入「短命線」。
7. 放在 Page 2 中間左邊。

⚠️ 點很多時 Power BI 會自動取樣，右上角可能出現提示，屬正常。

✅ 檢查：短命線（X=1）左邊的點集中在下方小資本區，橘色點比例明顯偏高。

## 4. 分解樹（短命公司成因）— Page 2

1. 點空白處 → 視覺效果窗格點 **分解樹**（樹狀分支的圖示）。
2. 拖曳欄位：
   - `短命公司率` → **分析**
   - 以下 5 個欄位依序拖到 **說明依據**：`資本額級距`、`地址群聚`、`產業關鍵字`、`公司型態`、`縣市`
3. 展開分支（Demo 時也照這個順序點）：
   - 點根節點「短命公司率 8.0%」旁的 **+** → 選 **資本額級距**
   - 點「10萬以下」那一格旁的 **+** → 選 **地址群聚**
4. **不要選「高值」或「低值」（AI 拆分）**，它會挑到金門這種樣本很少的縣市。
5. 放在 Page 2 中間右邊，拉寬一點讓三層都看得到。

✅ 檢查：全台 8.0% → 10萬以下 23.6% → 群聚地址 **37.5%**（一般地址 17.7%）。

> 存檔時分解樹會記住展開狀態。如果想讓 Demo 時現場展開，存檔前把分支收合回根節點。

## 規則（不然 Kelly 合併時貼不過去）

- **只新增圖表**，不要新增、刪除或改名欄位、量值、表格、頁面。
- 需要新量值或新欄位，先在群組講。
- 顏色：短命／「1年以下」用紅色、群聚地址用橘色，其他用預設色。
- 檔名：`名字_圖表_日期_版本.pbix`，例如 `Tim_圖表_1124_V1.pbix`；改版就上傳新檔（V2、V3），舊檔不用刪。


## Kelly：23:00 合併與兩頁連動（在彙整版上做）

### 合併

1. 從 GitHub 下載 `tim/`、`mars/` 最新的 `.pbix`。
2. 開 `底稿.pbix` → **另存新檔** 成 `彙整版_1124_V1.pbix`。
3. 另外開組員的檔案（會是另一個 Power BI 視窗）→ 點選要搬的圖表（按住 Ctrl 可一次選多個）→ **Ctrl+C** → 切回彙整版、點到同一頁 → **Ctrl+V**。
4. 自己的 4 張圖也用同樣方式從 `Kelly_圖表_1124_V1.pbix` 貼進來。
5. 對照 [`docs/dashboard_blueprint.md`](../docs/dashboard_blueprint.md) 排好位置。

### 鑽研（Drill-through）

1. 點 `Page2_診斷` 頁籤 → 點畫布空白處（不要選到任何圖表）。
2. 視覺效果窗格往下捲到 **鑽研** 區塊 → 把 `縣市`、`產業關鍵字` 拖到「在此新增鑽研欄位」。
3. **保留所有篩選** 開啟。
4. Page 2 左上角會自動出現「←」返回按鈕。
5. 測試：回 Page 1 → 在橫條圖「臺北市」按右鍵 → **鑽研** → **Page2_診斷**，Page 2 標題應變成「短命公司剖析：臺北市」。在編輯畫面按返回按鈕要用 **Ctrl + 點擊**。

### 同步篩選器

1. 上方 **檢視** → **同步交叉分析篩選器**（右側會多一個窗格）。
2. 點 Page 1 的 `資料年度` 篩選器 → 在同步窗格把兩頁的 **同步**（左欄）和 **可見**（右欄，眼睛）都打勾。
3. `公司型態` 篩選器同樣設定。

### 編輯互動

1. 點 Page 1 的圓環圖 → 上方 **格式** → **編輯互動**。
2. 其他圖表右上角會出現小圖示 → 在堆疊直條圖上點 **篩選**（漏斗圖示），不要用「醒目提示」。
3. 再按一次 **編輯互動** 關閉。

### 完成合併後

存檔，上傳到 GitHub 的 [`彙整版/`](../彙整版/)，在群組通知大家。
