# Kelly｜Page 1 後半＋ Page 2 診斷核心

這個資料夾放 Kelly 自己的圖表檔（`.pbix`）和上台逐字稿。做圖步驟、DAX 和踩坑紀錄都在 [`docs/作戰手冊.md`](../docs/作戰手冊.md)。

## 負責的圖表

- 群組橫條圖（縣市排名）
- 100% 堆疊直條圖（資本額級距 × 存活區間）
- 散佈圖（資本額 vs 存活年數）
- 分解樹（短命公司成因）
- 合併後：鑽研、同步篩選器、編輯互動

## 檔案

- 圖表檔：`Kelly_圖表_日期_版本.pbix`（例如 `Kelly_圖表_1125_V2.pbix`），改版就上傳新檔。

## 上台逐字稿

> [!CAUTION]
> 🔴 **V12 修正**：舊版寫「Ctrl + 點擊上一頁回 Page 1，再點頁籤切回 Page 2 解除臺北篩選」，**這樣解除不了**：鑽研帶進來的「臺北市」會一直留在 Page 2，分解樹會顯示 8.2%（臺北）而不是 8.0%（全台）。改成在 Page 2 直接清除篩選（步驟 ⑤）。

**① Page 1｜橫條圖**

[動作指令：滑鼠移到橫條圖「臺北市」，停住讓提示框出現]

「看縣市，臺北市 27,616 家解散最多。但家數多不代表風險高，滑鼠停上去看短命率，臺北是 8.2%；六都裡反而是臺中 9.7% 最高。」

**② Page 1｜堆疊直條圖**

[動作指令：指向最左邊「10萬以下」那根的紅色區塊，再指「100-500萬」]

「真正拉開差距的是資本額。紅色是存活不到一年：資本額 10 萬以下的公司短命率 23.6%，100 到 500 萬的只有 3.6%，差了 6 倍。」

**③ 鑽研到 Page 2**

[動作指令：在橫條圖「臺北市」按右鍵 → 鑽研 → Page2_診斷]

「我們從臺北市鑽研進 Page 2，標題自動變成臺北市。右上角卡片顯示，臺北的解散公司有 32.6% 登記在『群聚地址』，也就是同一個地址有 3 家以上公司解散。」

**④ Page 2｜散佈圖**

[動作指令：滑鼠圈出短命線左側、下方的點]

「散佈圖一個點是一家公司。短命線左邊的點，大多擠在底部小資本區，而且橘色的群聚地址特別多。」

**⑤ 清除臺北篩選**（🔴 V12 新步驟）

[動作指令：右側篩選窗格 → `縣市`「臺北市」→ 按橡皮擦清除（或鑽研區點 ✕）；確認分解樹根節點變回 8.0%]

「接下來看全台。」

**⑥ Page 2｜分解樹**

[動作指令：分解樹開檔時「資本額級距」已展開 → 點「10萬以下」旁的「+」→ 選「地址群聚」（如果只看到根節點，先點根節點「+」→ 資本額級距）]

「用分解樹把兩個因素疊起來。全台短命率 8%；資本額 10 萬以下跳到 23.6%；如果又登記在群聚地址，短命率是 **37.5%**，將近三家有一家活不到一年。同樣小資本但在一般地址的是 17.7%，差了一倍。接下來交給 Mars。」

[動作指令：把滑鼠交給 Mars]

> 約 1 分 50 秒。超時就先刪「右上角卡片 32.6%」那句。存檔前：分解樹收回根節點、Page 2 不要留著臺北市篩選。

### 備用問答

- 問「金門短命率最高？」→ Kelly：「金門 5 年只有 179 家，樣本太少，所以沒有拿來下結論；六都裡臺中市 9.7% 最高。」
- 問「為什麼不算解散率？」→ Kelly：「這份清冊只有解散的公司，沒有各縣市的公司總數，所以我們改比較『短命率』，它不受各縣市公司多寡影響。」
