## 第一步：自己打地基（19:00–20:00）

照 [`docs/作戰手冊.md`](../docs/作戰手冊.md) 的「任務 2A」匯入 60 個 CSV、「任務 2B」用 DAX 加欄位與量值、建好 `Page1_總覽`／`Page2_診斷` 兩頁，並對到驗算數字：108,281／8,697／15,953／1,067。不用等別人，做完直接開始做圖。

## 開始前準備

1. 開啟自己做完任務 2A、2B 的 Power BI 檔，先對到驗算數字（任務 2B 最後）。
2. **檔案 → 另存新檔**，存成 `自己名字_圖表_1124_V1.pbix`（例如 `Tim_圖表_1124_V1.pbix`）。之後都在這個檔案上做。
3. 左側切到 **報表檢視**（長條圖圖示），下方頁籤應有 `Page1_總覽`、`Page2_診斷` 兩頁。
4. 畫面右側有兩個窗格：
   - **視覺效果**：選圖表類型、放欄位、調格式（筆刷圖示＝格式、放大鏡圖示＝分析）
   - **資料**：所有欄位和量值都在 `解散清冊` 底下（量值前面有計算機圖示）

**通用做法**：先點一下畫布空白處 → 在「視覺效果」窗格點圖表圖示 → 畫布出現空白圖表 → 從「資料」窗格把欄位**拖曳**到「視覺效果」窗格的對應格子（例如「X 軸」）→ 拖圖表邊角調大小、拖中間移位置。

> 一定要先點空白處再選圖表類型，不然會把已經選取的圖表換掉。

**做完後**：對照每張圖的 ✅ 數字 → **檔案 → 儲存** → GitHub 進入自己名字的資料夾 → **Add file → Upload files** → 拖入 `.pbix` → 寫「名字 圖表 V1」→ **Commit changes** → 在群組說一聲。

## 1. 交叉分析篩選器 ×2

**篩選器 A：資料年度**

1. 點畫布空白處 → 視覺效果窗格點 **交叉分析篩選器**（漏斗加清單的圖示）。
2. 把 `資料年度` 拖到 **欄位**。
3. 點視覺效果窗格的 **筆刷圖示（格式化您的視覺效果）** → **交叉分析篩選器設定** → **選項** → **樣式** 選 **磚**，變成一排按鈕。
4. 拉成扁長條，放在 Page 1 最上方左邊。

**篩選器 B：公司型態**

1. 點空白處 → 再新增一個交叉分析篩選器。
2. 把 `公司型態` 拖到 **欄位**。
3. 格式 → 交叉分析篩選器設定 → 樣式選 **下拉式清單**。
4. 放在篩選器 A 右邊。

✅ 檢查：點「2021」，其他圖表數字會跟著變；再點一次取消。

## 2. KPI 卡片 ×4

每張卡片重複以下步驟：

1. 點空白處 → 視覺效果窗格點 **卡片**（寫著 123 的圖示）。
2. 把量值拖到 **欄位**（新版 Power BI 叫 **資料**）。
3. 拉成小方塊，4 張並排放在篩選器下方。

| 卡片 | 拖入的量值 | 應顯示（年度全選時） |
| --- | --- | --- |
| 1 | `總解散家數` | 108,281（若顯示 108.28K：格式 → 圖說值 → 顯示單位選「無」） |
| 2 | `中位數資本額` | 1,000,000 |
| 3 | `平均存活年數` | 11.5 |
| 4 | `短命公司率` | 8.0% |

## 3. 折線與群組直條圖（5 年趨勢）

1. 點空白處 → 視覺效果窗格點 **折線與群組直條圖**（直條上面有一條線的圖示）。
2. 拖曳欄位：
   - `資料年度` → **X 軸**
   - `總解散家數` → **直條 y 軸**
   - `短命公司率` → **折線 y 軸**
3. 格式（筆刷圖示）：
   - **資料標籤** → 開啟（直條和折線都會顯示數字）
   - **次要 Y 軸** → 確認是開啟（折線用右邊的百分比刻度）
   - **標題** → 文字改成「5 年解散家數與短命率」
4. 放在 KPI 卡片下方左邊，約佔畫面一半寬。

✅ 檢查：直條 20,201 → 20,913 → 21,342 → 22,490 → 23,335；折線 9.4% → 9.4% → 7.7% → 7.2% → 6.7%。

## 4. 區域分佈圖（地圖）

1. 點空白處 → 視覺效果窗格點 **區域分佈圖**（填色的地圖圖示，不是有圓點的「地圖」）。
2. 拖曳欄位：
   - `縣市` → **位置**
   - `短命公司率` → **工具提示**
3. 讓顏色深淺代表解散家數：
   - 格式 → **填滿色彩** → 點 **fx** 按鈕
   - **格式樣式** 選「漸層」；**我們應該根據哪個欄位？** 選 `總解散家數`
   - 最低值選淺色、最高值選深紅 → **確定**
   - （舊版 Power BI 若欄位格子有 **色彩飽和度**，直接把 `總解散家數` 拖進去即可）
4. 放在趨勢圖右邊。

⚠️ 地圖空白或出現錯誤：
- **檔案 → 選項及設定 → 選項 → 全域 → 安全性** → 勾選「使用地圖和區域分佈圖視覺效果」→ 確定後重開檔案。
- 還是不行：把 **位置** 改放 `地圖位置` 欄位。
- 臺灣以外出現顏色：滑鼠移到出錯的地方看是哪個值，告訴群組。

✅ 檢查：雙北、臺中顏色最深；滑鼠移到臺北市會顯示短命率 8.2%。

## 5. 圓環圖（公司型態）

1. 點空白處 → 視覺效果窗格點 **圓環圖**（中間空心的圓）。
2. 拖曳欄位：
   - `公司型態` → **圖例**
   - `總解散家數` → **值**
3. 格式 → **詳細資料標籤** → **標籤內容** 選「類別，總計百分比」。
4. 放在 Page 1 下方中間（左邊留給 Kelly 的橫條圖、右邊留給 Kelly 的堆疊直條圖）。

✅ 檢查：有限公司約 80.9%、股份有限公司約 19.1%。

## 規則（不然 Kelly 合併時貼不過去）

- **只新增圖表**，不要新增、刪除或改名欄位、量值、表格、頁面。
- **名稱三人要一模一樣**：公式從 [`powerbi/dax/`](../powerbi/dax/) 複製貼上，表名一律 `解散清冊`、頁面 `Page1_總覽`／`Page2_診斷`。
- 需要新量值或新欄位，先在群組講。
- 顏色：短命／「1年以下」用紅色、群聚地址用橘色，其他用預設色。
- 檔名：`名字_圖表_日期_版本.pbix`，例如 `Tim_圖表_1124_V1.pbix`；改版就上傳新檔（V2、V3），舊檔不用刪。
