### 診斷用的 3 個關鍵發現

- **資本額越小越短命**：10 萬以下的短命率 **23.6%**，是 100–500 萬級距（3.6%）的 6.6 倍。
- **地址群聚**：5 年內同一地址 ≥3 家解散的有 2,190 個地址、15,953 家公司，短命率 **18.5%**，一般地址只有 6.2%。小資本又在群聚地址的 3,394 家，短命率 **37.5%**（一般地址的小資本公司為 17.7%）。群聚地址的公司 56.5% 在臺北市；臺北市解散公司有 32.6% 登記在群聚地址。
- **產業差異**：名稱含「行銷」短命率 12.8%、「餐飲」12.7%、「顧問」9.9%；「建設」3.9%、「工程」5.6%。行銷、餐飲的中位存活只有 3.5–3.7 年。

小縣市（金門 179 家短命率 14.0%、臺東 235 家 11.1%）樣本少，上台只當參考；六都中臺中市 9.7% 最高。群聚地址很可能是商務中心或代辦登記地址，這是推論，報告時用「可能」字眼。

## 任務 2B：DAX 初學者版 — 一次加一欄

先分清楚兩種公式：

- **計算資料行**：在表上多加一欄，每一列各算一次，就像 Excel 把公式往下拉。用來做「分類」，例如每家公司屬於哪個縣市。
- **量值**：算出一個總數字給圖表用，就像樞紐分析表的加總。用來做「數字」，例如總解散家數。

**新增計算資料行的操作（每一欄都重複）**：左側切到資料表檢視 → 右側點 `解散清冊` → 上方 **資料表工具** → **新增資料行** → 把公式列預設的「資料行 =」刪掉 → 貼上一個公式 → 按 Enter。**一個公式 = 一欄，照編號順序做**，因為後面的欄會用到前面的欄。出現紅字錯誤，多半是表名或欄名打錯。

完整公式：[`powerbi/dax/calculated_columns.dax`](../powerbi/dax/calculated_columns.dax)（①–⑰）、[`powerbi/dax/measures.dax`](../powerbi/dax/measures.dax)（量值）。

| 步驟 | 編號 | 欄位 | 白話說明 |
| --- | --- | --- | --- |
| 1 日期與存活 | ① | 設立日期 | 民國 651208 → 1976/12/08。除以 10000 取整數得民國年，加 1911 就是西元；中間兩位是月、最後兩位是日 |
| | ② | 解散日期 | 同上。①② 做完後資料類型選 **日期**，0651208 應變成 1976/12/8 |
| | ③ | 資料年度 | 取檔名前 4 個字，`202101.csv` → `2021` |
| | ④ | 存活年數 | 設立到解散相差幾天，除以 365.25 變成年 |
| | ⑤ | 存活區間 | `SWITCH ( TRUE (), 條件1, 結果1, … )`＝由上往下檢查，第一個成立的就回傳 |
| | ⑥ | 存活區間排序 | 給圖表排順序用，不然會依中文筆劃亂排 |
| 2 分類欄位 | ⑦ | 縣市 | 地址前 3 字，「台」統一成「臺」；沒地址標「地址缺漏」 |
| | ⑧ | 公司型態 | `CONTAINSSTRING`＝文字裡有沒有這個字。先檢查「股份有限」 |
| | ⑨ | 產業關鍵字 | 由上往下比對公司名稱，第一個對到的就是產業 |
| | ⑩⑪ | 資本額級距、排序 | 分成 8 級，給堆疊直條圖用 |
| | ⑫ | 地圖位置 | 地圖找不到縣市時的備援 |
| 3 異常標記 | ⑬ | 短命公司 | 活不到 1 年標 1，其他標 0 |
| | ⑭ | 同址解散家數 | 這個地址在整份清冊出現幾次（`REMOVEFILTERS`＝先看整張表） |
| | ⑮ | 地址群聚 | 同一地址 3 家以上解散 |
| | ⑯ | 資料品質 | 資本額為 0、地址或設立日期缺漏 |
| | ⑰ | 異常標記 | 合成一欄給 Page 2 篩選器 |

⑦–⑫ 做完後的 3 個點選設定：

1. 點 `存活區間` → 資料行工具 → **依資料行排序** → 選 `存活區間排序`；`資本額級距` 同樣設成依 `資本額級距排序`。
2. 點 `縣市` → 資料行工具 → **資料類別** 選「州或省」；`地圖位置` 選「位置」。
3. 點 `資本額`、`存活年數` → 資料行工具 → **摘要** 選「不要摘要」，散佈圖才會一點一家公司。

### 步驟 4：量值

**操作**：右側點 `解散清冊` → 上方 **常用** → **新增量值** → 貼一個 → Enter。

| 量值 | 白話用途 | 用在哪裡 |
| --- | --- | --- |
| 總解散家數 | 有幾筆就是幾家 | 幾乎每張圖 |
| 平均資本額／中位數資本額 | 排除資本額 0 後的平均與中位數 | KPI 卡片 |
| 平均存活年數／中位數存活年數 | 平均活幾年 | KPI 卡片 |
| 短命公司家數／短命公司率 | 活不到 1 年的家數與比例 | 趨勢圖、分解樹、工具提示 |
| 短命率_全台基準／短命率_高於全台 | 不管篩選都算全部，用來比較「高出全台幾個百分點」 | Page 2 KPI |
| 地址群聚家數／地址群聚占比 | 登記在群聚地址的家數與比例 | Page 2 KPI |
| 資料異常筆數 | 資料品質有問題的筆數 | 結論 |
| Page2標題 | 鑽研進來時自動變成縣市名稱 | Page 2 標題卡片 |

格式：點量值 → **量值工具** → 格式選「百分比」、小數 1 位（`短命公司率`、`短命率_高於全台`、`地址群聚占比`）。

驗算：`總解散家數` = 108,281、`短命公司家數` = 8,697、`地址群聚家數` = 15,953、`資料異常筆數` = 1,067。
