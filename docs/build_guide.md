# 建置步驟（Power BI Desktop，全程點選＋ DAX）

本專案不撰寫 Power Query M 語言，資料匯入全部用介面點選完成，新欄位一律用 DAX 計算資料行建立。

## 1. 匯入 60 個月 CSV

1. 將 `data/raw/` 內 60 個 CSV 放在同一個資料夾（資料夾內不放其他檔案）。
2. Power BI Desktop → **常用** → **取得資料** → **更多…** → **資料夾** → 選取資料夾 → **確定**。
3. 檔案清單出現後 → **合併** 旁的箭頭 → **合併並載入**。
4. 「合併檔案」視窗的 **檔案原點** 選 `65001: Unicode (UTF-8)`，確認中文預覽正常 → **確定**。
5. 資料窗格中將資料表改名為 `解散清冊`。
6. 資料表檢視左下角列數應為 **108,281**；保留 `Source.Name` 欄（檔名，後續取年度）。
7. 資料類型：`核准設立日期`、`核准解散日期`、`資本額` 設為 **整數**；`代表人`、`序號` 從報表檢視中隱藏。

## 2. 計算資料行

公式全文見 [`powerbi/dax/calculated_columns.dax`](../powerbi/dax/calculated_columns.dax)，依編號 ①–⑰ 順序建立（資料表工具 → 新增資料行，一次一欄）。

| 編號 | 欄位 | 用途 |
| --- | --- | --- |
| ①② | 設立日期、解散日期 | 民國 7 碼轉西元日期（建立後資料類型設為「日期」） |
| ③ | 資料年度 | 由檔名取年度，供篩選器與趨勢圖 |
| ④–⑥ | 存活年數、存活區間、存活區間排序 | 公司壽命與分組 |
| ⑦–⑫ | 縣市、公司型態、產業關鍵字、資本額級距、排序、地圖位置 | 分類維度 |
| ⑬–⑰ | 短命公司、同址解散家數、地址群聚、資料品質、異常標記 | 異常偵測 |

建立後的點選設定：

- `存活區間`、`資本額級距` → 資料行工具 → **依資料行排序** → 對應的排序欄。
- `縣市` → **資料類別**「州或省」；`地圖位置` →「位置」。
- `資本額`、`存活年數` 的摘要維持預設；散佈圖在圖表內把 X、Y 軸摘要設為「平均」（值放 `統一編號`，逐點顯示）。

## 3. 量值

公式全文見 [`powerbi/dax/measures.dax`](../powerbi/dax/measures.dax)（常用 → 新增量值，一次一個）。`短命公司率`、`短命率_高於全台`、`地址群聚占比` 格式設為百分比、小數 1 位。
