# 儀表板配置藍圖

## 頁面互動

- **鑽研**：Page 2 設定鑽研欄位 `縣市`、`產業關鍵字`，從 Page 1 橫條圖右鍵鑽研進入。
- **同步篩選器**：`資料年度`、`公司型態` 兩頁同步。
- **編輯互動**：圓環圖對堆疊直條圖設為「篩選」。
