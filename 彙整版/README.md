# 彙整版（11/25 報告用）

主檔由 Kelly 保管，三人的圖表在這裡合併成一份。

| 檔案 | 說明 |
| --- | --- |
| `彙整版_日期_版本.pbix` | 合併 Tim、Kelly、Mars 圖表後的正式報表（兩頁），上台用這個 |

## 合併方式

1. 從 `tim/`、`mars/` 下載組員最新版 `.pbix`
2. 開 Kelly 自己的檔案，另存成 `彙整版_1124_V1.pbix`
3. 同時開組員的檔案，點圖表 → Ctrl+C → 切回彙整版同一頁 → Ctrl+V
4. 設定兩頁鑽研、同步篩選器，上傳到本資料夾

詳細步驟見 [`docs/作戰手冊.md`](../docs/作戰手冊.md)「任務 3B → Kelly：23:00 合併與兩頁連動」。

## 注意

- 三人的表名、欄位、量值、頁面名稱必須一模一樣，圖表才貼得過去
- 修改請通知 Kelly，避免兩人同時改同一份
- 上傳大小超過 25 MB 時，改用 GitHub Desktop 上傳
