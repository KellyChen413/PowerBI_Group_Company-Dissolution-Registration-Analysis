## 上台逐字稿

[動作指令：點異常標記篩選器「短命＋地址群聚」]

「同時符合短命和地址群聚的有 2,949 家。整份清冊裡，同一地址解散最多的在臺北市大安區，一個地址 5 年內就有 85 家公司解散。」

[動作指令：取消篩選器；在矩陣熱力圖展開「臺北市」的 +，指「行銷」那一列的「1年以下」]

「產業也有差異。名稱有『行銷』、『餐飲』的公司短命率約 13%，中位數只活 3.5 年左右；『建設』只有 3.9%。展開臺北市，『1年以下』那欄比例最高的是『行銷』，13.9%。」

「結論有三點。第一，解散家數逐年增加，但短命比例下降、解散公司的中位存活年數從 6.4 年拉長到 7.5 年，代表退場的多是經營較久的公司。第二，短命公司集中在小資本加群聚地址；公司法沒有最低資本額門檻，群聚地址可能是商務中心或代辦登記地址，反映『先登記再說』的試水溫型創業，這是我們的推論。第三，小資本加群聚地址可以當成風險訊號，給主管機關或銀行排核查優先順序。另外資料品質上，有 1,067 筆資本額為 0、地址或設立日期缺漏，我們已標記出來。謝謝大家。」
