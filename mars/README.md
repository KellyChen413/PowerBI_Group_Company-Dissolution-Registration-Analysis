## 第一步：自己打地基（19:00–20:00）

照 [`docs/作戰手冊.md`](../docs/作戰手冊.md) 的「任務 2A」匯入 60 個 CSV、「任務 2B」用 DAX 加欄位與量值、建好 `Page1_總覽`／`Page2_診斷` 兩頁，並對到驗算數字：108,281／8,697／15,953／1,067。不用等別人，做完直接開始做圖。

## 開始前準備

1. 開啟自己做完任務 2A、2B 的 Power BI 檔，先對到驗算數字（任務 2B 最後）。
2. **檔案 → 另存新檔**，存成 `自己名字_圖表_1124_V1.pbix`（例如 `Tim_圖表_1124_V1.pbix`）。之後都在這個檔案上做。
3. 左側切到 **報表檢視**（長條圖圖示），下方頁籤應有 `Page1_總覽`、`Page2_診斷` 兩頁。
4. 畫面右側有兩個窗格：
   - **視覺效果**：選圖表類型、放欄位、調格式（筆刷圖示＝格式、放大鏡圖示＝分析）
   - **資料**：所有欄位和量值都在 `解散清冊` 底下（量值前面有計算機圖示）

**通用做法**：先點一下畫布空白處 → 在「視覺效果」窗格點圖表圖示 → 畫布出現空白圖表 → 從「資料」窗格把欄位**拖曳**到「視覺效果」窗格的對應格子（例如「X 軸」）→ 拖圖表邊角調大小、拖中間移位置。

> 一定要先點空白處再選圖表類型，不然會把已經選取的圖表換掉。

**做完後**：對照每張圖的 ✅ 數字 → **檔案 → 儲存** → GitHub 進入自己名字的資料夾 → **Add file → Upload files** → 拖入 `.pbix` → 寫「名字 圖表 V1」→ **Commit changes** → 在群組說一聲。

## 1. 動態標題卡片

1. 點空白處 → 視覺效果窗格點 **卡片**（寫著 123 的圖示）。
2. 把 `Page2標題` 拖到 **欄位**（新版叫 **資料**）。
3. 格式：
   - **類別標籤**（新版叫 **標籤**）→ 關閉（不要顯示下面那行小字）
   - **圖說值** → 字型大小調到 20 左右
4. 拉成長條，放在 Page 2 最上方左邊，當作這一頁的標題。

✅ 檢查：顯示「短命公司剖析：全台」。合併並設好鑽研後，從 Page 1 臺北市鑽研進來會變成「短命公司剖析：臺北市」。

## 2. 異常標記篩選器

1. 點空白處 → 視覺效果窗格點 **交叉分析篩選器**。
2. 把 `異常標記` 拖到 **欄位**。
3. 格式 → **交叉分析篩選器設定** → **選項** → **樣式** 選 **磚**（變成按鈕）。
4. 放在標題右邊。

✅ 檢查：點「短命＋地址群聚」，下方 KPI 第一張卡片會變成 2,949；再點一次取消。

## 3. KPI 卡片 ×3

每張卡片重複：點空白處 → **卡片** → 把量值拖到 **欄位**。3 張並排放在標題下方。

| 卡片 | 拖入的量值 | 應顯示（全台、無篩選） |
| --- | --- | --- |
| 1 | `短命公司家數` | 8,697（若顯示 8.70K：格式 → 圖說值 → 顯示單位選「無」） |
| 2 | `短命率_高於全台` | 0.0%（全台時是 0；鑽研到某縣市後會顯示高出或低於全台幾個百分點） |
| 3 | `地址群聚占比` | 14.7% |

卡片 2 的標題建議改成「與全台差距」：格式 → **標題** → 開啟 → 文字輸入「短命率與全台差距」。

## 4. 矩陣熱力圖（縣市 × 產業 × 存活區間）

1. 點空白處 → 視覺效果窗格點 **矩陣**（表格中有格線的圖示，不是「資料表」）。
2. 拖曳欄位：
   - `縣市` → **資料列**
   - `產業關鍵字` → **資料列**（放在 `縣市` 下面，形成兩層，左邊會出現 **+** 可以展開）
   - `存活區間` → **資料行**
   - `總解散家數` → **值**
3. 改成百分比：點 **值** 格子裡 `總解散家數` 旁的小箭頭 → **將值顯示為** → **資料列總計百分比**。（每一列加起來 100%，才能比較各縣市「1年以下」佔多少）
4. 上色變熱力圖：
   - 格式 → **儲存格元素** → **背景色彩** → 開啟 → 點 **fx**
   - **格式樣式** 選「漸層」→ 最低值白色、最高值深紅 → **確定**
5. 排除「地址缺漏」：右側 **篩選** 窗格 → 此視覺效果上的篩選 → `縣市` → 取消勾選「地址缺漏」。
6. 確認欄的順序是「1年以下、1-3年…20年以上」；如果亂掉，代表任務 2B 的「依資料行排序」沒設好，在群組講。
7. 放在 Page 2 最下方，拉寬到整個畫面。

✅ 檢查：點臺北市的 **+** 展開產業，「1年以下」那欄裡顏色最深的格子，就是逐字稿裡要念的 [產業]，彩排前把它填進逐字稿。

## 規則（不然 Kelly 合併時貼不過去）

- **只新增圖表**，不要新增、刪除或改名欄位、量值、表格、頁面。
- **名稱三人要一模一樣**：公式從 [`powerbi/dax/`](../powerbi/dax/) 複製貼上，表名一律 `解散清冊`、頁面 `Page1_總覽`／`Page2_診斷`。
- 需要新量值或新欄位，先在群組講。
- 顏色：短命／「1年以下」用紅色、群聚地址用橘色，其他用預設色。
- 檔名：`名字_圖表_日期_版本.pbix`，例如 `Tim_圖表_1124_V1.pbix`；改版就上傳新檔（V2、V3），舊檔不用刪。
