# 公司解散登記清冊分析（2021–2025）｜Power BI 分組實作

用 Power BI 分析 5 年、108,281 筆公司解散登記資料，從「敘述性分析」找出現象，再用「診斷性分析」找出哪些公司最容易在設立一年內就解散。

> AI 數據培訓課程 Power BI 分組實作（3 人小組：Kelly、Tim、Mars），以 Power BI Desktop 直接進行 Live Demo。

## 分析問題

**什麼樣的公司最容易在一年內就解散？**

## 資料

| 項目 | 內容 |
| --- | --- |
| 來源 | 經濟部公司解散登記清冊（課程提供） |
| 期間 | 2021/01–2025/12，共 60 個月 CSV |
| 筆數 | 108,281 筆 |
| 欄位 | 序號、統一編號、公司名稱、公司所在地、代表人、資本額、核准設立日期、核准解散日期 |

資料特性與處理：日期為民國 7 碼（如 `0651208`），以 DAX 轉為西元日期；`代表人` 欄 99.9% 為空，不使用；資本額為 0、地址或設立日期缺漏共 1,067 筆，以「資料品質」欄標記而非刪除。

## 主要發現

1. **解散變多，但短命比例下降**：解散家數由 2021 年 20,201 家增至 2025 年 23,335 家（+15.5%），但存活未滿 1 年的比例由 9.4% 降至 6.7%，解散公司的中位存活年數由 6.4 年拉長至 7.5 年。
2. **小資本最容易短命**：資本額 10 萬以下的公司短命率 23.6%，是 100–500 萬級距（3.6%）的 6.6 倍。
3. **地址群聚是第二個風險因子**：同一地址 5 年內有 3 家以上公司解散（2,190 個地址、15,953 家），短命率 18.5%，一般地址僅 6.2%。
4. **兩者疊加風險最高**：資本額 10 萬以下且登記在群聚地址的 3,394 家公司，短命率 **37.5%**；同樣小資本但在一般地址者為 17.7%。
5. **產業差異**：名稱含「行銷」「餐飲」的公司短命率約 13%、中位存活約 3.5 年；「建設」僅 3.9%。

群聚地址可能是商務中心或代辦登記地址，此為推論，需外部資料驗證。完整數字見 [`analysis/summary_stats.md`](analysis/summary_stats.md)。

## 技術重點

- **Power BI 資料夾合併**：60 個月 CSV 以「取得資料 → 資料夾 → 合併並載入」一次匯入，保留 `Source.Name` 推導資料年度。
- **DAX 計算資料行（17 欄）**：民國轉西元日期、存活年數與區間、縣市擷取與「台／臺」統一、以 `CONTAINSSTRING` 判斷公司型態與產業關鍵字、以 `CALCULATE` + `REMOVEFILTERS` 計算同址解散家數。
- **DAX 量值（13 個）**：短命率、全台基準比較（`REMOVEFILTERS`）、地址群聚占比、鑽研動態標題（`ISFILTERED` + `SELECTEDVALUE`）。
- **Python 驗算**：以 pandas 獨立計算 KPI 基準值，用來核對 Power BI 結果（[`analysis/profile_data.py`](analysis/profile_data.py)）。

## 限制

- 清冊只包含解散公司，沒有各縣市現有公司總數，因此以「短命率」比較而非「解散率」。
- 產業以公司名稱關鍵字判斷，約 6 成公司名稱無關鍵字，歸為「其他」。
- 金門、臺東等縣市樣本數少，短命率僅供參考。
